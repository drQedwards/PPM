# SAT proof-of-computation manifest (draft)

A draft manifest that records what `two_sat.py` and `three_sat.py` computed on a fixed benchmark set, with a certificate for every answer, and one SHA-256 Merkle root over the whole record. It is a record of finite computations, not a complexity result.

## Claims (copied from the manifest's `claims` field)

- Not a proof that P = NP, and not a proof that P ≠ NP. P versus NP is open.
- 2-SAT is in P; this has been known since Aspvall, Plass, Tarjan (1979). `two_sat.py` implements that linear-time O(n + m) procedure. Nothing new is claimed.
- 3-SAT is NP-complete. `three_sat.py` is DPLL with unit propagation: exact on every finite 3-CNF, exponential time in the worst case, no polynomial bound claimed.
- Small benchmark sizes; no performance or asymptotic claim is made from them.

## Contents

| Field | What it holds |
| --- | --- |
| `sources` | Repo, commit, path, git blob SHA-1, sha256 and size of the solver, test, doc and `SAT.*` files (pmll `8e49955`, drQedwards/math `6a5264c`), plus sha256 of the harness scripts |
| `environment` | Python version, platform, gcc, drat-trim commit and source sha256 |
| `tests` | Each test command, exit code, full output and output sha256 |
| `instances` | Per instance: DIMACS sha256 and path, decision, solver stats, cross-checks, and a certificate |
| `summary` | Counts by family and decision, verification counts, mismatch counts |
| `merkle` | Tree definition, leaf count, root |
| `anchor_draft` | The unsigned `pmll_anchor` call that would commit the root (not executed) |

Benchmarks (427 instances): the exact instances generated by the family 002 and family 001 tests in drQedwards/math (seeds 11 and 7), the 8-clause UNSAT core, the empty formula, the explicit 4-clause 2-SAT UNSAT, and 40 extra uniform random instances (3-SAT at clause ratio 4.26 for n = 12 to 40, 2-SAT at ratio 1.0 for n = 12 to 100, seed 20261006).

## Certificates

- **SAT:** a witness assignment (signed literals). Checking it is linear in the formula size. 412 of 412 verify.
- **UNSAT:** a DRUP proof (DRAT text format, no deletions) emitted by `tools/sat_proof/drup_dpll.py`, a mirror of `three_sat.solve_3sat` that writes, at each conflict, the clause negating the current unflipped decisions. Each lemma is RUP with respect to the formula and earlier lemmas, and the last lemma is the empty clause. The harness asserts that the mirror returns exactly the same result dict as `three_sat.py` on every instance; `tests/test_drup_dpll.py` checks the same agreement and the RUP property in CI. All 15 UNSAT proofs are accepted by [drat-trim](https://github.com/marijnheule/drat-trim) (`s VERIFIED`), and drat-trim rejects a bogus proof as a control. The 3 UNSAT 2-SAT instances also carry an implication-path certificate (x leads to ¬x and ¬x leads to x), checkable in linear time.
- DPLL refutations have no short certificate in general: these proofs have one lemma per conflict, so they grow with the search.

Cross-checks: the pmll and drQedwards/math copies of the solvers agree on all 427 instances, `two_sat.py` agrees with the DPLL decider on every 2-SAT instance, and exhaustive search agrees on all 403 instances with n ≤ 16.

## Merkle root

```
723cbe658e875821ac2fbb5cd8bfd6937f3a61a1aba7e6665aa6ae5e2c6e6078
```

RFC 6962 tree over 446 leaves. Leaf hash `SHA256(0x00 || canonical_json(leaf))`, node hash `SHA256(0x01 || left || right)`. Canonical JSON is `json.dumps(sort_keys=True, separators=(",", ":"), ensure_ascii=False)` in UTF-8. Leaves, in order: header (schema, status, generated_at), claims, environment, summary, each source file, each test run, each instance. The header includes the generation time, so rebuilding the manifest gives a new root; the root above belongs to the manifest generated 2026-10-06T22:02:59-04:00.

## Verifying

```bash
python tools/sat_proof/verify_manifest.py /path/to/manifest-dir \
  --expect-root 723cbe658e875821ac2fbb5cd8bfd6937f3a61a1aba7e6665aa6ae5e2c6e6078
```

The directory holds `manifest.json`, `instances/*.cnf` and `proofs/*.drat`. The script recomputes the root, re-hashes every instance and proof, checks that every witness is a consistent assignment that satisfies its formula, and runs drat-trim (from `$DRAT_TRIM`, `PATH`, or `tools/drat-trim/drat-trim` under the manifest directory) on every UNSAT proof.

- Without `--expect-root`, a match only shows that the manifest agrees with itself; anyone who edits an instance can also edit the stored root. Compare against the root published here (or anchored later).
- Without drat-trim the script fails. `--hash-only` accepts a partial check (UNSAT proofs hash-checked, not verified) and says so in its result line.

The manifest, instances and proofs currently live on the build box (`/workspace/sat-proof/`). They are not yet published, so the root cannot be re-derived from this repository alone.
